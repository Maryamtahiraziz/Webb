Lecture 2: Tiered Web Architecture

Client-server model, HTTP and web architecture

Summary

This lecture explains how the web works using the client-server model, URLs, DNS and HTTP, the organisations that set web standards, the types of web applications and tiered web architecture.

Topics Covered

  • Client-server request and response
  • URL, DNS, HTTP and HTTPS
  • Web standards (W3C, WHATWG, ECMA, IETF)
  • Static and dynamic web applications
  • One-tier, two-tier and three-tier architecture
