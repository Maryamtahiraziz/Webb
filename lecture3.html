Lecture 3: HTML Basics

This lecture introduces HTML as the structure of a web page, including the document skeleton, tags, elements and attributes, headings, links, images, lists and tables.

Topics Covered

  • DOCTYPE, html, head and body
  • Tags, elements and attributes
  • Headings and text formatting
  • Links and images
  • Lists and tables
